# Gauntlet

Gauntlet simulates, records and evaluates AI agents in a mock world, finds the ways they fail or can be attacked, and turns those findings into regression tests and runtime policies.

- **Start here:** the [quickstart](quickstart.md) gets you from checkout to a first report in about five minutes, offline, with no model call.
- **Understand it:** [concepts](concepts.md).
- **Do something:** the [guides](guides/targets.md).
- **Look something up:** the reference ([CLI](reference/cli.md), [REST API](reference/api.md), [check language](reference/check-language.md)), the [threat taxonomy](reference/taxonomy.md) and [benchmarks](../benchmarks/index.md).
- **Before you point it at anything real:** [safety and responsible use](safety.md).

Nothing here phones home. The documentation site has no analytics and builds offline.
