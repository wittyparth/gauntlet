# Hall of Failures

Eight scenarios modelled on publicly reported agent failures, each on its own fictional world
(`pack.yaml` lists `worlds`; every scenario names one). Run it with
`gauntlet run packs/hall_of_failures --suite hall --target <agent>`. See `SOURCES.md` for the
neutral incident descriptions and the verified sources. Scenarios 07 and 08 carry an
`attack` reference to an imported library attack whose payload is pre-placed in the world.
