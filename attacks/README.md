# Attack data

* `taxonomy.yaml`: the 17 threat categories (`Attack.category` values) with OWASP LLM 2025, OWASP
  Agentic (T-numbers) and MITRE ATLAS ids. Every id was verified against the official pages on the
  `verified_on` date in the file header (URLs in `sources`); unverifiable ids are left out.
* `objectives.yaml`: objective templates keyed `category:vector` for importers (P2-2). Objectives
  are limited to canary exfiltration, unauthorised tool calls, policy bypass and cross-user data
  leakage in the mock world.
* `library/<source>/<category>.yaml`: imported attacks (P2-2). Load and validate with
  `gauntlet_core.security.load_attacks`.

## Imported library (P2-2)

`library/<source>/<category>.yaml` is generated by `python -m tools.import_attacks` (never edited
by hand). Sources, pins and licences, verified from each upstream repository's LICENSE file and
the GitHub licence API on 2026-11-20:

* AgentDojo: MIT, version 0.1.35 (repo commit 089ed468), read with
  `uv run --with agentdojo==0.1.35` (goals and attack templates from the package).
* InjecAgent: MIT, commit f19c9f2c79a4, `data/attacker_cases_*.jsonl` from a checkout.
* garak: Apache-2.0, version 0.17.1 from PyPI (licence read at repo commit 725160beb813),
  whitelisted probe classes only.
* promptfoo: MIT, commit 0d4978bace53, static `Prompt:` examples in
  `src/redteam/plugins/*.ts`.

`NOTICES.md` (generated by `python -m tools.import_attacks.notices`) carries the licence texts;
`library/skipped.json` records everything skipped and why. The OASIS SARIF schema is not vendored
(its licence is not identifiable), see `gauntlet_core.security.sarif`. `wrappers.yaml` holds the
neutral framing templates of the `wrap:<id>` mutation (P2-3).
